# atsam3x8e-pac

Peripheral access crate for the Microchip ATSAM3X8E (and SAM3X8ERT), a
Cortex-M3 microcontroller.

The code is generated by svd2rust 0.37 from Atmel's SVD, with patches that
fix register and field definitions. The generated code is published as is,
so building this crate does not need svd2rust.

Most users want [`sam3x-hal`](https://crates.io/crates/sam3x-hal), which is
built on this crate.

## Features

- `rt`: the device's vector table and the `#[interrupt]` attribute, through
  cortex-m-rt. Enable it in a binary.
- `critical-section`: `Peripherals::take()`, through the critical-section
  crate.
