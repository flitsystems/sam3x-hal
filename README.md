# sam3x-hal

Rust support for the Microchip SAM3X family (SAM3X8E, SAM3X8ERT), Cortex-M3.

| Crate | Content |
|---|---|
| `atsam3x8e-pac` | Peripheral access crate generated by svd2rust from the vendored SVD. The generated code is committed, so consumers never need svd2rust. |
| `sam3x-hal` | Hardware abstraction layer on top of it, implementing embedded-hal 1.0. |
| `arduino-due` | Board support: the pins under the names printed on the board, the board's clock tree, its memory layout, and a cargo runner that flashes through the programming port. |
| `sam3x-hal-examples` | One binary per peripheral, written for the Arduino Due. |

## Build

The target (`thumbv7m-none-eabi`) and the toolchain are pinned by `.cargo/config.toml` and `rust-toolchain.toml`. `nix develop` provides rustup, git and bossac, nothing else is needed.

```sh
ci/check.sh        # what CI runs
ci/msrv.sh         # the published crates on their minimum Rust version
```

## Running an example

`cargo run` flashes an Arduino Due through its programming port. The runner, `arduino-due/flash.sh`, needs an `objcopy` (from cargo-binutils, LLVM or the Arm GNU toolchain) and `bossac` (in the nix dev shell), and takes the port from `DUE_PORT` (default `/dev/ttyACM0`):

```sh
DUE_PORT=/dev/ttyACM0 cargo run --release --bin blinky
```
